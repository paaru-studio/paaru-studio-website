# Paaru Studio - Redesigned Website

A modern, sleek website redesign for Paaru Studio with design inspiration from Brandemic.in

## Features

### Design Elements (Inspired by Brandemic)
- **Dark Theme**: Modern dark background (#0a0a0a) with subtle gradients
- **Purple Gradient Accents**: Beautiful gradient from #6366f1 to #8b5cf6
- **Clean Typography**: Inter font family for modern, professional look
- **Smooth Animations**: Fade-in effects, parallax scrolling, and hover interactions
- **Glass-morphism**: Navbar with backdrop blur effect
- **Card-based Layout**: Elevated cards with hover effects

### Content (From Original Paarustudio.com)
- Complete agency information and services
- All advertising solutions including:
  - Bengaluru Metro advertising
  - Digital screens in malls
  - TATA IPL 2026 OTT plans
  - Podcast production services
- Client testimonials
- Contact section

### Technical Features
- **Responsive Design**: Mobile-first approach with breakpoints
- **Intersection Observer**: Smooth scroll animations
- **Parallax Effects**: Dynamic hero section
- **Smooth Scrolling**: Navigation with smooth scroll behavior
- **Interactive Elements**: Hover effects and transitions
